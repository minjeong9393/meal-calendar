# 신철민정 식단표 (광고 없는 식단 기록 웹앱)

모바일 우선 식단 기록 달력입니다. 외부 CDN·광고·추적 없이 동작하고, 기록은 사용하는 브라우저(기기) 안에 저장됩니다.
부부/가족이 같은 달력을 실시간으로 함께 쓸 수 있습니다(가족 연동).

- 앱: https://minjeong9393.github.io/meal-calendar/
- 홈 화면에 추가하면 주소창 없는 앱처럼 열립니다 (Android Chrome `앱 설치` / iPhone Safari `홈 화면에 추가`). 홈 화면 이름은 `신철민정 식단표`.
- 이 저장소의 앱은 **빈 달력**으로 시작합니다. 개인 식단 기록은 저장소에 포함되어 있지 않습니다.

## 쓰는 법
- 상단 `하루` / `주간` / `월간` 으로 보기를 바꾸고, 날짜를 눌러 식단을 추가·수정·순서변경·삭제합니다.
- 상단 아이콘: 가족 연동, 통계, 랜덤 추천(내가 적은 식단에서 한 가지 골라 1탭 추가), 더보기(⋮) — JSON 내보내기·불러오기, 색상 테마.
- 기록은 브라우저 `localStorage`(`meal_calendar_v1`)에 저장됩니다. 브라우저 데이터를 지우면 함께 사라지니 가끔 `⋮ → JSON 내보내기`로 백업하세요.
- 다른 기기로 옮길 때는 내보낸 JSON 파일을 `⋮ → JSON 불러오기`로 열면 됩니다.

## 가족 연동 (부부 실시간 공유)
1. 위쪽 `가족 연동`(구름 아이콘) → **새 가족 방 만들기**. `meal-xxxxxx` 코드가 만들어지고 지금 기기의 식단이 함께 올라갑니다.
2. **남편 초대 링크 복사** → 카톡으로 보내면, 받은 사람은 링크를 누르는 것만으로 같은 방에 연결됩니다. (코드를 직접 적어 `가족 코드로 참여하기`도 가능)
3. 한쪽에서 식단을 적으면 다른 쪽 화면에 바로 나타납니다. 화면 색·종류 색은 기기마다 따로 저장됩니다.
- 실시간 연결은 Firebase Realtime Database(익명·공개 규칙)의 REST + SSE를 쓰고, 외부 SDK는 쓰지 않습니다. 방 코드를 아는 기기만 접근할 수 있습니다.
- `이 기기 연동 해제`는 이 기기의 연결만 끊고 식단 기록은 남깁니다.

## 파일
- `index.html` — 앱 전체 (CSS/JS/아이콘 인라인, 단일 파일)
- `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png` — 홈 화면 설치용
- `sw.js` — 오프라인 실행용 서비스워커 (앱 껍데기만 캐시, 기록은 저장하지 않음)

## 개발 메모
빈 달력 시드는 의도된 설정입니다. 이 배포본은 개인 기록이 공개되지 않도록 원본 소스의 시드 데이터를 비워서 빌드했습니다.

광고·추적 스크립트를 넣지 않는 것이 이 앱의 조건입니다.
