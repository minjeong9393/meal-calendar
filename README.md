# 식단 달력 (광고 없는 식단 기록 웹앱)

모바일 우선 식단 기록 달력입니다. 외부 CDN·광고·추적 없이 동작하고, 기록은 사용하는 브라우저(기기) 안에만 저장됩니다.

- 앱: https://minjeong9393.github.io/meal-calendar/
- 홈 화면에 추가하면 주소창 없는 앱처럼 열립니다 (Android Chrome `앱 설치` / iPhone Safari `홈 화면에 추가`).
- 이 저장소의 앱은 **빈 달력**으로 시작합니다. 개인 식단 기록은 저장소에 포함되어 있지 않습니다.

## 쓰는 법
- 상단 `하루` / `주간` / `월간` 으로 보기를 바꾸고, 날짜를 눌러 식단을 추가·수정·순서변경·삭제합니다.
- 상단 아이콘: 통계, 랜덤 추천(내가 적은 식단에서 한 가지 골라 1탭 추가), 더보기(⋮) — JSON 내보내기·불러오기, 색상 테마.
- 기록은 브라우저 `localStorage`(`meal_calendar_v1`)에 저장됩니다. 브라우저 데이터를 지우면 함께 사라지니 가끔 `⋮ → JSON 내보내기`로 백업하세요.
- 다른 기기로 옮길 때는 내보낸 JSON 파일을 `⋮ → JSON 불러오기`로 열면 됩니다.

## 파일
- `index.html` — 앱 전체 (CSS/JS/아이콘 인라인, 단일 파일)
- `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png` — 홈 화면 설치용
- `sw.js` — 오프라인 실행용 서비스워커 (앱 껍데기만 캐시, 기록은 저장하지 않음)

## 개발 메모
빈 달력 시드는 의도된 설정입니다. 이 배포본은 개인 기록이 공개되지 않도록 원본 소스의 시드 데이터를 비워서 빌드했습니다.

광고·추적 스크립트를 넣지 않는 것이 이 앱의 조건입니다.
